# Vila Tila — Luxury 5-Star Holiday Villa Website

Official website for **Vila Tila** (`CCL380`), an exclusive 5-star private holiday villa situated in Prozor near Otočac, Lika, Croatia, right by the crystal-clear river Gacka.

## Features

- **Image-First Modern Architecture:** Showcases 43 high-resolution verified photographs categorized by Architecture & Exterior, Pool & Wellness, Living & Dining, Bedrooms & Bathrooms, and River Gacka Nature.
- **Bilingual Experience:** Seamless instant toggle between English (EN) and grammatically natural Croatian (HR).
- **Year-Round Heated Wellness:** Highlights the 21 m² indoor heated swimming pool with starry sky ceiling and handcrafted Finnish cedar sauna.
- **European Date Format (`DD/MM/YYYY`):** Custom interactive EU datepicker with Monday as the first day of the week, input auto-masking, and date validation.
- **Accessible Fullscreen Lightbox:** Keyboard operable (`Left`/`Right` arrows, `Escape`), focus trap, mobile swipe gesture support, and detailed screen reader descriptions panel.
- **W3C WCAG 2.2 Level AA & AAA Compliance:** High-contrast focus rings (`:focus-visible`), full `aria-live` status regions, skip-to-content bypass link, and touch targets exceeding 44×44px.
- **100% SEO Optimized:** Schema.org `VacationRental` + `FAQPage` JSON-LD structured data, OpenGraph, Twitter Cards, Local SEO geo-coordinates, and zero Cumulative Layout Shift (CLS).

## Tech Stack

- **HTML5:** Semantic landmarks (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, `<footer>`).
- **Vanilla CSS3:** Custom responsive design system with luxury dark theme (`#0a0e14`) and gold accents (`#d4af37`), glassmorphism, fluid typography, and `@media (prefers-reduced-motion: reduce)`.
- **Vanilla JavaScript:** Dependency-free client-side i18n engine, EU datepicker, focus-trapped lightbox modal, and smooth navigation.

## GitHub Pages Deployment

The repository is pre-configured with `.nojekyll` for immediate hosting on GitHub Pages:

1. Go to repository **Settings** > **Pages**.
2. Select **Branch:** `main`, **Folder:** `/ (root)`.
3. Save and access the live site.
